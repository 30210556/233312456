AI 비서 & TTS 음성 변환기

질문을 던지거나 텍스트를 바로 AI 음성(mp3)으로 변환하고 Firebase에 기록합니다
현재 구조: GitHub Pages 화면 → Google Apps Script 서버 → OpenAI API → 데이터 수신
[추가 기능]: 생성된 모든 질문과 음성 변환 기록은 실시간으로 Firebase Realtime Database에 누적 저장됩니다.
